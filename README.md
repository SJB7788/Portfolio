# Portfolio Website

Hello, I’m SeungJae. This is my personal portfolio website.

I built this project to revisit core frontend fundamentals after spending most of 2024 focused on backend development. Before entering the BCIT CST program, I put a lot of focus on learning HTML, CSS, and JavaScript, and this project was a way to evaluate how much of those fundamentals I still remembered without relying on frameworks or AI assistance

The frontend is implemented using **HTML, CSS, and JavaScript**. For general guidance and reference, I used MDN documentation and community resources, such as Stack Overflow

In addition, I had been learning a new language, **Go**, and used this project as an opportunity to build a simple web server. While I am still a beginner, building and deploying this server helped reinforce Go concepts I had learned

The application is containerized using **Docker** for deployment. Since I was new to not only containerizing Go applications, but to the Go language itself, I used AI-assisted guidance for the Docker configuration. I then reviewed and modified the setup to better understand how Go compiles binaries, handles dependencies, and runs inside a container. This process improved my understanding of Go application structure and Docker deployment
